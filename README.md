StreetKash MVP

StreetKash is a technology concept exploring sponsored public Wi-Fi access for high-traffic locations, with the goal of making reliable connectivity more accessible while creating value for sponsors and network operators.

This repository contains an early interactive prototype created to visualize and explore the StreetKash concept.

About the Prototype

The current prototype demonstrates possible user, sponsor, and operator experiences within a StreetKash connectivity ecosystem.

It explores concepts such as:

- Public Wi-Fi access
- Captive-portal experiences
- Sponsored connectivity
- Sponsor/brand dashboards
- Network monitoring
- Operator dashboards
- Connectivity and usage visualization

Prototype Status

This is not a production deployment.

The interface is an early proof-of-concept and contains simulated/demo data for demonstrating how different parts of the system could work.

Displayed values such as network usage, solar output, users, advertising activity, connectivity statistics, and infrastructure status should therefore not be interpreted as real-world measurements.

Project Direction

The StreetKash concept has evolved since this prototype was created.

The current direction focuses on validating the feasibility of sponsored public Wi-Fi infrastructure at high-traffic locations before moving into physical deployment.

The project is currently being explored around:

- User demand and connectivity challenges
- Captive-portal access
- Network architecture
- Backhaul connectivity
- Bandwidth management
- Power and backup systems
- Sponsor/advertiser value
- Infrastructure monitoring
- Business viability

The current prototype should therefore be viewed as an early iteration of the project, rather than a representation of the final product or business model.
